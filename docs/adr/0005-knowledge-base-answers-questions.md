# Questions are answered from an airport Knowledge base instead of going to staff

When the LLM recognises a message as a Question, such as "where do I drop my luggage", the Passenger gets an answer from a curated airport Knowledge base. Nothing is sent to staff unless the Passenger chooses "Send to staff anyway". This keeps staff for real problems and gives Passengers an instant answer. The LLM must answer only from the Knowledge base and must say when it does not know, because invented directions in an airport are worse than none. The answer is labelled as automatic, never presented as coming from a person. The demo Knowledge base is simulated and labelled as such.
