# Staff have individual accounts and see only their Team's Issues, from phase 1

Each staff member has their own account, belongs to one Team (for example Cleaning or Security), and sees only the Issues routed to that Team. A duty manager sees everything. This replaces the earlier plan of one shared staff view for phase 1. Cleaning staff should not receive security Issues and security should not receive cleaning Issues, and individual accounts also make the audit log meaningful. The cost is that routing now matters: an Issue the LLM routes to the wrong Team could go unseen. So the design includes safeguards: the duty manager sees all Issues, and staff can hand an Issue to another Team. The exact Team list is still to confirm.
