# Grouping Reports into Issues, and staff summaries, are done by the LLM

The LLM decides whether a new Report describes an existing Issue, because simple rules cannot tell that "the toilet is dirty" and "there is no toilet paper" at the same toilet are different problems. To keep this cheap and predictable, the LLM only compares a new Report against a small set of candidate Issues that are close in time and place. The exact window and what counts as close are still to set. The Staff app shows how many people reported an Issue ("3 people reported missing toilet paper") and an LLM-written summary. The original Reports always stay one tap away, so a summary never hides context.
