# The passenger web app is one free-text field, not category buttons

The Passenger now sees one text field ("Report an issue in the airport or ask for help..."), replacing the category buttons planned earlier. The LLM works out whether the message is a Report or a Question, and for a Report its category, Severity and Team. One field is simpler to understand. It lets us catch Questions that should never reach staff, and Passengers can no longer pick the wrong category. The trade-off is that typing is harder than tapping for elderly or one-handed Passengers. The built-in dictation on phone keyboards helps, and quick-start suggestions under the field are an open idea.
