# Flare: Design V1 (chosen design)

Static HTML mock-ups of the Flare screens. Open any file in a browser to see it at its real size (phone screens are 390x844, the poster is A4 at 794x1123).
All data is simulated.

## Design tokens
- Navy (headers, text): #0B2545
- Cobalt (the one main action per screen): #2457E6
- Pale blue (page background): #EAF0FB
- Tint (notices, tags): #DCE6FA
- Muted text: #44587A, hairlines: #CBD8EF
- Red, only for 112 / emergency / Critical: #C8102E (pale red #FDECEE)
- Font: Instrument Sans (Google Fonts), 400/500/600/700; nothing below 16px
- Radii: cards 20-24px, buttons and fields 16px, pills 999px, navy header has 28px rounded bottom corners
- Buttons: 56px tall (staff 48px)
